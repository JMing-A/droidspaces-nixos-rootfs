# 使用指南（面向普通用户）

> 上级索引：[README.md](../README.md)

## 1. 我要下载镜像

1. 打开 <https://github.com/JMing-A/droidspaces-nixos-rootfs/releases>
2. 选最新的 Release（带 `Latest` 标签那个）
3. 按你的手机架构下载：
   - 近年绝大多数 Android 手机 → `...-aarch64-....tar.xz`
   - 模拟器 / 部分 x86 平板 → `...-x86_64-....tar.xz`
4. 不确定选哪个变体？先下 `NixOS-Minimal` 试，能开机再考虑 `Minimal-Tools`

Release 页面每个包旁边还带一个 `SHA256SUMS-*.txt`，用来校验完整性。

## 2. 校验下载是否完整

Linux / macOS：

```sh
sha256sum NixOS-Minimal-Kernel-5.10-and-up-Droidspaces-rootfs-aarch64-*.tar.xz
```

Windows PowerShell：

```powershell
Get-FileHash .\NixOS-Minimal-*.tar.xz -Algorithm SHA256
```

把结果和 `SHA256SUMS-*.txt` 里的值对比，一致就说明没下坏。
不一致就重下，不要将就——坏包会导致容器开机失败且症状很难查。

## 3. 导入 Droidspaces

1. 打开 Droidspaces App
2. 新增容器 → 从本地 rootfs 压缩包导入
3. 选择刚下载的 `.tar.xz`
4. 分配磁盘空间（建议至少 4 GB，NixOS 解压后体积不小）
5. 启动

首次启动会比较慢（systemd 要生成 machine-id、初始化 nix store 数据库）。

## 4. 首次进系统后建议做的事

```sh
# 看系统版本
nixos-version

# 看装了哪些包
nix-env -q

# 换源（国内网络）
nix.settings / 或直接编辑 /etc/nix/nix.conf 加：
# substituters = https://mirrors.tuna.tsinghua.edu.cn/nix-channels/store https://cache.nixos.org
```

`minimal` 变体没带 `git` / `curl`，需要的话自己装：

```sh
nix profile install nixpkgs#git nixpkgs#curl
```

## 5. 我要只构建某一个变体

进仓库 → **Actions** → **Build NixOS rootfs** → **Run workflow**：

```
variant = minimal 最小镜像
system  = aarch64-linux（手机 / ARM）
publish = false
```

大约 5～10 分钟。构建完在本次 run 页面底部 **Artifacts** 区域能直接下到包，
不会产生 Release，也不会影响 `rootfs.json`。

## 6. 我要自己加一个变体

假设要加一个「装了 python3 的镜像」：

**第一步**，新建 `nix/minimal-python.nix`：

```nix
{ pkgs, ... }: {
  environment.systemPackages = with pkgs; [
    bash
    coreutils
    nano
    python3
  ];
}
```

**第二步**，在 `flake.nix` 的 `profiles` 里加一行：

```nix
profiles = {
  minimal = ./nix/minimal.nix;
  minimal-tools = ./nix/minimal-tools.nix;
  minimal-python = ./nix/minimal-python.nix;   # 新增
};
```

**第三步**，在 `variants.json` 末尾加一条：

```json
{
  "id": "minimal-python",
  "name": "NixOS - 带 Python",
  "file": "NixOS-Minimal-Python-Kernel-5.10-and-up",
  "distro": "NixOS",
  "description": "在最小镜像基础上多装了 Python 3和 pip，适合直接开始写脚本。",
  "output": "nixosRootfsTarballs",
  "attr": "minimal-python",
  "experimental": false
}
```

**第四步**，本地校验：

```sh
python3 scripts/gen_rootfs_json.py --lint
```

输出里应该能看到 `minimal-python`，没报错就提交。下一次跑 workflow 时它会自动出现在矩阵里。

## 7. 常见疑问

**为什么构建是手动的？**
NixOS 求值很容易被上游 nixpkgs 变动搞挂。自动跑意味着你无法控制的半夜失败。
手动意味着每次出包都是你自己确认过的。

**为什么两个变体体积差不多？**
`minimal-tools` 只多装了几个小工具，但它们会带入依赖闭包（比如 git 带 perl、curl 带 TLS）。
实际差异以 Release 页面的包大小为准。

**包能用在别的容器 App 里吗？**
理论上可以，只要那个 App 支持导入 systemd 容器的 tar 包。但本仓库只对 Droidspaces 做过验证。

**内核要 5.10 以上，我的手机够吗？**
2021 年以后发布的手机基本都是 5.10 或更新。不确定就查设置里的内核版本，
或先下载试启动，起不来 App 会报错。
